# Data

wasmlet bundles no datasets. It does vendor test inputs, listed here with
their source and license.

| path | what | source | license |
|---|---|---|---|
| `tests/spec/core/*.wast` (90 files, 3.5 MB) | official WebAssembly core spec tests | [WebAssembly/spec](https://github.com/WebAssembly/spec), branch `wg-2.0`, commit `fffc6e12fa454e475455a7b58d3b5dc343980c10`, directory `test/core/` (the `simd/` subdirectory is excluded) | Apache-2.0, see `tests/spec/LICENSE` |
| `tests/spec/SHA256SUMS` | checksums of the vendored files | generated from the files above | — |
| `tests/spec/expected.tsv` | per-file pass/fail/skip baseline | generated by `wasmlet-spec --write-expect` | MIT (this repository) |
| `fixtures/wat/*.wat` | hand-written WebAssembly text programs (hello, fib, loop, sieve, matmul) | written for this repository | MIT |
| `fixtures/rust/` | Rust sources of the guest programs | written for this repository | MIT |
| `fixtures/wasm/*.wasm` | `hello`, `wc` and kernel guests compiled for `wasm32-wasip1` (`opt-level = "s"`, LTO, stripped) | built from `fixtures/rust/` by `scripts/build-fixtures.sh` | MIT; the binaries also contain code from the Rust standard library (MIT OR Apache-2.0) |
| `fixtures/text/poem.txt` | eight lines of text for the `wc` demo | written for this repository | MIT |

Verification: `scripts/verify-spec.sh` checks the vendored suite against
`SHA256SUMS` (offline, part of `make check`); `scripts/verify-spec.sh
--upstream` downloads each file from the pinned commit and checks it hashes
to the same value. Both passed on 2026-10-25.

Generated at run time, never committed: fuzz inputs are produced from a
seeded PRNG and `wasm-smith`; failing inputs (none so far) would be written
to the git-ignored `fuzz-artifacts/`.
